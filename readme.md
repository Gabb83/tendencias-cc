## Tendência em Ciência da Computação

Esse repositório é dedicado para a realização dos exercícios e desafios da disciplina de Tendência em Ciência da Computação.

### Desafio Ouvidoria:
- Análise Comparativa de Similaridade: calcula a similaridade entre diferentes textos, permitindo identificar padrões e relações entre eles.
  - **Ferramentas e Técnicas**: Bag-of-Words, TF-IDF, Word Embeddings. Foi utilizado a similaridade de cosseno para medir a similaridade entre os textos.
